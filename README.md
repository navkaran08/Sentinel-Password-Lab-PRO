# 🔐 Sentinel Password Lab PRO

## 🔒 Security & Privacy Notice

Never enter a real password that you currently use for an important account.

Always use a **randomly generated or disposable password** for testing.

The core password analysis is designed to run locally in the browser. The optional compromised-password lookup, when enabled and available, uses a privacy-preserving approach rather than sending the complete password to the external service.

If an external security check cannot be completed, the application should report that verification is **unavailable** rather than incorrectly claiming that a password was not compromised.

> **Security recommendation:** Use a password manager, unique passwords, and MFA or passkeys whenever supported.

## 🧠 Analysis Method

Sentinel Password Lab PRO evaluates multiple password characteristics rather than relying only on character-type requirements.

Analysis can include:

* Password length
* Character diversity
* Character-set size
* Repetition
* Sequential patterns
* Common-password patterns
* Date and year patterns
* Estimated search space
* Shannon entropy
* Attack-rate scenarios
* Optional compromised-password status

> Crack-time results are **estimates**, not guarantees. Real-world resistance depends on hashing algorithms, work factors, hardware, rate limiting, MFA/passkeys, attacker knowledge, and other security controls.
